## 👨‍💻 About me

I'm a **Flutter &amp; Node.js developer** who turns ideas into production apps for **Android, iOS and the Web**, from one codebase and in both Arabic and English.

I like owning a feature end to end: the screens, the state behind them, the API they talk to, and the release that puts them in people's hands. By day I build **GPS tracking, fleet &amp; dispatch** apps at [Bawq](https://www.bawq.com); on the side I'm shipping an **AI career assistant** that runs live voice mock interviews.
